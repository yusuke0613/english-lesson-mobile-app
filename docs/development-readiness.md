## 4. HTMLと本体実装を区別する箇所

- `recording` の切替と固定の `00:04` 表示だけで、マイク録音はない。送信後の英文・添削も固定値。
- 読み上げボタンは操作メッセージを表示するだけで、音は再生しない。
- 保存は元の表示環境にある任意の `window.openai.setWidgetState` へのUI状態保存。会話履歴・SQLite・通常ブラウザーの永続化を実装していない。
- 「今日の15分」は常に復習から始まる。実装では初回/復習対象なしを分岐する。
- 復習画面は英文を最初から表示する。別日の「音声だけで返答できた」の確認では英文を隠し、開いた事実を記録する。
- 日付、表現カードの達成状態、担当業務の例、まとめの保存済み表示はサンプル。本人が練習していない表現を実績に加えない。
- アイコン、外側のCSS、調整UIは元のホストに依存する部分がある。React Native本体ではネイティブUIとして作り直す。
