録音はAAC/M4A候補、mono・64 kbpsを設定。1秒未満、90秒超過、5,000,000 bytes超過、空ファイルを拒否する。自動停止後も本人の操作なしに送信しない。iOSの自動停止後はSDKの時間計測がリセットされるため、直前の計測値を保持する（250ms間隔。実ファイルの長さとAPI受理は未検証）。音声中断を検出したら停止し、削除失敗時はファイル参照と再試行UIを残す。

アプリ強制終了後の一時ファイル回復・残存ファイルの掃除はTask 4で実装する。Task 2時点では端末DB・AIクライアントは未実装だった。以下にTask 3での変更を記録する。

音声設定をPCM WAV（16kHz、mono、16-bit）に変更した。サーバーで実データ長から時間を検査するため。許可チャンクはfmt/data/JUNK/FLLRに限定し、その境界もテストした。iPhoneが生成する実WAVの適合、音質、文字起こし受理は未確認。

現在は名前の1問で、本人の送信操作 → 文字起こし → コーチの返答 → 読み上げまでのコードがある。失敗時に自動再送せず、得られた文字起こしは画面内に残す。SQLite保存・仕事の質問への遷移・まとめ画面・翌日復習はまだない。設定手順は[API接続の準備](api-setup.md)。

## 本人のiPhoneでの手順

2026-10-04のサーバー準備：実際のD1へ `DB` bindingを修正し、初期マイグレーション・owner-iphone登録を実施。未適用migrationが0件で、既存ローカルコードが登録ハッシュと一致し有効であることを確認した。APIの型チェック・33テスト・Worker dry-runも成功。AIキー設定・Worker公開・iPhone接続の確認はまだない。

1. WindowsとiPhoneを同じWi-Fiにつなぎ、SDK 57対応のExpo Goを用意する。
2. `mobile/` で `npm.cmd start`。QRコードをiPhoneのカメラで読み、Expo Goで開く。
3. 「練習を始める」→「お手本を聞く」→「会話の練習へ」。意味・答え方を開閉する。
4. 「録音する」でマイクを許可し、架空の名前で2〜3秒話して停止する。録音の長さが表示されたら「録音を破棄」。まず録音・破棄だけを確認する。
5. 下記の権限拒否・ロック・自動停止などを確認し、機種/iOS/Expo Go版と結果を追記する。

Expo Goでは共有アプリ側の権限表示になるため、`app.json` の日本語マイク説明文の表示は独立した開発ビルドでも確認する。
